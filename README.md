# QVAC Local AI Assistant

A simple local AI assistant built with Tether's QVAC SDK.

This project runs an AI language model directly on the user's device using QVAC. The application does not require an external AI API key for inference.

## Features

- Runs AI inference locally on the device
- Uses Tether's QVAC SDK
- Uses the Llama 3.2 1B Instruct model
- Generates text responses locally
- No external AI API is required

## Requirements

- Windows, macOS, or Linux
- Node.js 22.17 or newer
- npm 10.9 or newer
- A compatible QVAC runtime
